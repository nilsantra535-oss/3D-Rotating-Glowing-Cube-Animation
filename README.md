# 🧊 3D Rotating Glowing Cube Animation

A pure HTML and CSS 3D rotating cube animation featuring smooth Y-axis rotation, gradient surfaces, and a glowing ambient shadow effect beneath the cube.

## ✨ Features
- **Pure CSS 3D Transforms:** Built using `transform-style: preserve-3d`, `rotate`, and `translateZ` without any JavaScript.
- **Smooth Infinite Rotation:** Continuous 360-degree rotation along the Y-axis with an isometric tilt (`rotate: x -30deg`).
- **Ambient Glow Effect:** Uses a blurred pseudo-element (`::after`) beneath the cube to simulate a neon reflection on the floor.
- **Lightweight & Responsive:** Zero external dependencies; centered cleanly using CSS Flexbox.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3** (Custom Properties / CSS Variables, 3D Transforms, Keyframe Animations)
